# COVE Design System

Balanced, warm, general-purpose presentation system. Deep teal, apricot, butter and ivory. Context supplied by user.

## Start
Open index.html offline. All rules are static text; no scripts, external fonts or remote images required.

AI reading order: README → full index.html → tokens.json → SHAPES.md → CHARTS.md → AI-INSTRUCTIONS.md → STORYTELLING.md → VALIDATION.md. A repo URL alone does not guarantee every file was read.

## Package
- index.html: full documentation, shape lab, crop lab, six chart specimens and three deck compositions.
- tokens.json: palette, slide/web typography, geometry, image and chart values.
- SHAPES.md: 12 shape and 12 image-mask contracts, exact crop math and path.
- CHARTS.md: 28 chart contracts, type selection, anatomy, integrity and underlying examples.
- example-data.json: illustrative chart values, including null vs0 and waterfall reconciliation.
- mask-source.svg: synthetic crop demo source, not a photograph.
- AI-INSTRUCTIONS.md: execution contract and prompt.
- STORYTELLING.md: English/Indonesian guidance.
- contrast-report.json, VALIDATION.md, CHANGELOG.md: checks, limits and history.
- cove-preview.png: composition preview.
- chart-preview.png: chart gallery preview.
- charts/: six standalone illustrative SVGs (vector objects, not native editable chart masters).
- cove-design-system.zip: portable package.

## Scope
Documentation, SVG chart examples and scaled layout specimens. No actual client deck, PDF deck, editable PPTX/Slides master or interactive chart app. Photo masks are specified and demonstrated with synthetic vector imagery; real photos require crop/rights/resolution QA. No third-party assets or font binaries redistributed. No open-source license automatically assigned; COVE is a working name without trademark clearance.

Reference: Sustainify by Nuril Fikriyah, https://www.behance.net/gallery/201574659/Sustainify-Multipurpose-Presentation-Template . Palette, shape geometry and chart rules are COVE decisions, not claimed exact source specifications. Repository: https://github.com/imragsn/cove-design-system .
